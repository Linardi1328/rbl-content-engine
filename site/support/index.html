Help & contact

Support

Need help with RBL Content Engine, social-account authorization, or a publishing result? You can contact RBL directly without creating a GitHub account.

Contact support privately

Email richb.linardi@gmail.com for general assistance and technical questions. The address is shown here so you can also copy it into your preferred email application.

When describing a problem, include the affected platform, a short description, and any non-sensitive error details. Do not send passwords, OAuth tokens, API keys, identity documents, or unredacted account logs.

Privacy and data-rights requests

For access, correction, deletion, or revocation requests involving data under RBL's control, use the same private email contact. Please also read the Privacy Policy for details on revoking platform access and handling local publishing records.

Public technical bug reports (optional)

If you prefer to report a non-sensitive technical bug in public, you can use the GitHub Issues tracker. GitHub Issues are public and may require a GitHub account. Private email remains available for all support questions.

Never post personal or private information in public GitHub Issues. This includes names, email addresses, account identifiers, screenshots containing personal information, unpublished media, credentials, access tokens, and raw logs. Use redacted examples only.

Account security

If you suspect a connected social account has been compromised, revoke the application's authorization in that platform's settings, secure the account directly with the platform, and contact RBL privately for help with any RBL-controlled local authorization state.
